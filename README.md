## 📖 About

**MovieMagic** provides a seamless interface for both cinema managers and end-users to manage and book movie tickets.

Built using Python and standard web technologies, it allows:
- Customers to view movies, select showtimes, pick seats, and book tickets.
- Admins to add new movies, manage screens, and monitor bookings.

---

## 🚀 Features

✅ View all movies and showtimes  
✅ Seat layout and selection  
✅ Book tickets for any show  
✅ Admin management interface (add/delete movies, control showtimes)  
✅ Basic frontend with movie posters, show cards, and interactive UI  

---

## 🛠️ Technologies

- **Backend**: Python (Flask assumed)
- **Frontend**: HTML, CSS, JavaScript
- **Templating**: Jinja2 (via Flask `render_template`)
- **Folder Structure**:
  - `static/` → CSS, JS, images
  - `templates/` → HTML templates
  - `images/` → Posters and visuals
  - `app.py` → Main application
